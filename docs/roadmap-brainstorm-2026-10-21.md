# Liang AI 创新点/优化点头脑风暴（2026-10-21）

> **来源**：v2.3.4 发版后，4 个子 agent 并行头脑风暴（产品创新 / 交互体验 / AI 能力 / 工程质量四个互补视角，各 12 点共 48 项），交叉去重归并为 6 大主题 30 项。
> **用途**：后续迭代的选题池。每完成一项就在表格里标注状态；发现新想法随时追加。
> **阅读建议**：先看「交叉发现」和「推荐路线」，再按主题细看。每项都标了成本（低/中/高）与来源视角。

---

## 一、交叉发现（单视角看不到的结构性结论）

1. **FTS5 是隐藏的地基**：会话全文搜索、记忆检索、截图视觉记忆、情景记忆层、轻量 RAG——5 个点都跑在 SQLite FTS5 全文检索这层上。先建底座，后面全是加法。
2. **记忆二期被三个视角共同指向**：策展台（先看见）→ 自动沉淀（再自动）→ 分层衰减（后精细）。三者不冲突，是先后关系。
3. **主动智能有现成飞轮**：结构化提取（待办）→ 自动沉淀（记忆）→ 晨报/跟进（触达）→ 新会话 → 再沉淀。三个功能互为原料。
4. **home_page 拆分是 UI 候选的前置**：底部 Tab、气泡全宽化、胶囊收纳全压在这个 1600 行文件上——先拆再改，风险完全不同。
5. **气泡全宽化与横滑操作有协同**：全宽气泡给横滑留更大热区，建议同批做。

## 二、推荐路线（融合四视角 Top 3 + 已确认候选）

### 第一梯队 · 快赢（天级，随时可插空做）
触觉反馈体系 → Token 水位仪表盘 → 上下文透视镜 → 智能路由规则版 → 会话独立草稿 → DB schema 测试根治 → 发版脚本化

### 第二梯队 · 地基（周级，决定后面所有事）
FTS5 检索底座 → 备份/导出 → home_page 拆分 → 流式智能跟随

### 第三梯队 · 质变（月级，产品升维）
- **记忆二期**：策展台 → 自动沉淀 → 分层衰减
- **自定义 HTTP 工具**（产品视角的差异化之王）
- **主动智能引擎**：晨报 + 承诺跟进（依赖记忆二期产出）
- **分层上下文压缩**（长会话还债）

### 与已确认候选的关系
底部 Tab 导航和气泡全宽化属体验层重构，与上表不冲突；建议做它们之前先插队 home_page 拆分。

## 七、主题五：AI 基础设施

## 八、主题六：工程与数据安全

## 十、明确不做清单（反过度工程声明，来自工程视角）

| 不做 | 理由 |
|---|---|
| get_it / 复杂 DI 框架 | 单人项目构造函数传参足够，DI 框架是纯认知税 |
| freezed / json_serializable 全家桶 | model 数量有限，手写+现有测试覆盖可控 |
| Clean Architecture 分层重构 | 现有 SseParser→ApiService→Provider 链路清晰，分层是仪式不是收益 |
| WebDAV / 云同步 | 手动导出覆盖 90% 风险，云同步引入服务端心智负担 |
| Crashlytics / Sentry | 无后台服务，本地日志+手动分享足够 |
| 多 flavor / 环境矩阵 | 单人单环境，无此需求 |
| 为覆盖率而补测试 | 370 项已覆盖核心路径，只补「迁移链」这类真实风险盲区 |

1. 项目是什么

主流 AI 应用把你的对话存在别人的服务器上，把记忆锁在它的账号里。Liang AI 是对这件事的个人回答：一个完全跑在你手机上的 AI 助手——

  • Local-first：聊天历史、长期记忆、知识卡片全部存本地 SQLite；
  • Key 自持：API key 存 Android Keystore 加密的安全存储，数据库里只存空串——数据库泄露也拿不到 key；
  • 零遥测：无任何上传、无统计埋点；
  • BYOK（Bring Your Own Key）：接任意 OpenAI 兼容服务（OpenAI / DeepSeek / Moonshot / SiliconFlow / 本地 Ollama），Base URL + Key 即插即用，多服务商一键切换。

3. 安装与快速上手（用户视角）

  1. 下载 APK：GitHub Releases 页下载最新 app-release.apk，安装（允许「安装未知应用」）。
  2. 配模型服务：首次启动 → 设置 → Model Service → 填 Base URL + API Key（任意 OpenAI 兼容服务）。
  3. 开聊：新建会话即可流式对话；长按消息可蒸馏成卡片。
  4. 记忆自动生长：每轮会话后自动提取记忆，重要度分层；重要的钉选为永久。
  5. 备份：设置里一键备份/恢复（记忆与卡片包含在内）——换手机必备。

4. 从源码构建（开发者视角）

# 1. 环境：Flutter SDK（Dart SDK >= 3.12.2）+ Android SDK（minSdk 21）
git clone https://github.com/lvliang666666/liang-ai.git
cd liang-ai

# 2. 拉依赖
flutter pub get

# 3. 跑测试（可选，1158+ 用例）
flutter test

# 4. 构建 release APK
flutter build apk --release
# 产物：build/app/outputs/flutter-apk/app-release.apk
不要动 dependency_overrides：shared_preferences_android 钉在 2.4.28——2.5.x 会导致 release 构建启动白屏（pubspec.yaml 里有注释说明）。顺手升级依赖前先看这条。

5. 移植到新电脑（开发环境）

  1. 装 Flutter SDK（Dart ≥ 3.12.2）与 Android SDK，flutter doctor 全绿。
  2. git clone 本仓库（或拷目录，排除 build/ 与 tempfolds/）。
  3. flutter pub get → flutter test（确认 1158+ 用例绿）→ flutter build apk --release。
  4. 签名配置若在新机器缺失：检查 android/key.properties 与 keystore 文件是否随目录迁移（keystore 丢了就无法同签名更新发版，务必单独备份）。

6. 数据与安全设计

  • API key：flutter_secure_storage（Android Keystore 加密的 EncryptedSharedPreferences）；数据库只存空串；
  • 本地库：SQLite 存会话/记忆/卡片，FTS 全文索引；
  • 后台保活：flutter_foreground_task 前台服务（dataSync 类型）+ WakeLock；
  • 零遥测：无统计 SDK、无上传通道。

9. FAQ

Q1：支持 iOS 吗？

当前只有 Android。Flutter 代码理论上可跨平台，但 iOS 侧未做适配与发版。

Q2：换手机怎么迁移数据？

旧手机 App 内「一键备份」→ 导出文件传到新手机 → 新手机 App 内「恢复」。记忆与卡片都在备份里。

Q3：模型服务哪家能用？

任何 OpenAI chat/completions 兼容端点：OpenAI、DeepSeek、Moonshot、SiliconFlow、本地 Ollama 等。填 Base URL + Key 即可。

Q4：release 构建启动白屏？

十有八九是 dependency_overrides 被动了——把 shared_preferences_android 钉回 2.4.28。

Q5：和 Liang-AI-Desktop 什么关系？

姊妹项目：本仓库是 Android 端；Liang-AI-Desktop 是 Electron 桌面端（独立仓库、独立版本线）。

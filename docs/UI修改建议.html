═══════════════════════════════
一、复制操作反馈优化
═══════════════════════════════

【问题】
复制成功反馈使用系统默认 Toast（屏幕底部深色长条）：
1. 反馈位置远离复制按钮（动作点），视线需大幅移动
2. 覆盖底部输入栏，阻断正在进行的输入
3. 全宽深色长条视觉过重，与信息量不匹配

【修改方案：废弃底部 Toast，改为按钮内状态切换】
1. 触发：点击代码块右上角「复制」按钮
2. 反馈态（立即切换）：
   - 图标：复制图标 → 16dp 绿色对勾（#34C759）
   - 文案：「复制」→「已复制」，14sp，颜色不变
   - 按钮位置、尺寸不变，无布局跳动
3. 还原：1500ms 后恢复原状（150ms 淡出过渡，或直接还原）
4. 重复点击：重新计时（刷新 1500ms），不叠加、不闪烁

【兜底规范：全局 Toast（删除成功/网络异常等场景）】
- 位置：底部输入栏上方 8dp，水平居中，禁止覆盖输入栏
- 形态：深色胶囊 rgba(0,0,0,0.75)，高 36dp，内边距 10dp×16dp，
  全圆角，左右边距 ≥16dp
- 文案：14sp 白色，单行截断
- 动效：淡入 200ms ease-out，停留 2000ms，淡出 150ms ease-in
- 行为：无遮罩、不阻断底层点击；同时仅存在一个，新替旧

【验收标准】
1. 点击复制后按钮原地显示「✓已复制」，无底部弹条
2. 反馈期间输入栏可正常操作，无遮挡
3. 连续快速点击复制，状态正常刷新，无堆叠异常
4. 1.5s 后按钮还原为「复制」初始态

二、Skill 选择面板键盘适配
═══════════════════════════════

【问题】
面板形态为键盘样式附件，点击搜索框弹出软键盘后：
1. 搜索框（焦点元素）被键盘遮挡，消失在视野外
2. 面板高度未收缩或上移，内容区高度为 0，标题与键盘贴脸
3. 无滚动补偿，内容静默消失
4. 面板层级混乱：盖住输入栏但露出半截底部工具栏，无容器分隔
5. 无关闭按钮，退出路径不明确

【修改方案：改为标准 Bottom Sheet + 键盘适配】

1. 基础形态：
   - 触发：点「+」后键盘先收起，面板从底部滑出，250ms ease-out
   - 容器：白色面板，顶部圆角 16dp，最大高度 60% 屏高，可下拉关闭
   - 遮罩：rgba(0,0,0,0.4)，点击遮罩关闭
   - 标题：「选择 Skill」16sp 加粗左对齐，右侧 24dp 关闭图标（×）
   - 内容：Skill 列表项高 48dp（图标+名称+一句描述）；
     空状态显示「暂无可用 Skill」居中 14sp 灰字 #999
   - 层级：面板完整覆盖输入栏区域，不露半截旧 UI
   - 退出：点遮罩 / 下拉 / 点关闭，三种方式均可

2. 键盘适配（核心）：
   - 高度适配：监听键盘高度，面板整体上移至键盘上沿，
     内容区高度 = 面板高度 − 键盘高度，最小保留 240dp
   - 可见性：标题+搜索框固定面板顶部，键盘弹出时自动滚入视口，
     焦点元素距键盘上沿 ≥16dp
   - 滚动补偿：内容区可滚动，键盘弹出时自动滚动定位到搜索框
   - 动效：面板跟随键盘高度平滑过渡，时长与键盘动画一致（约 250ms），
     禁止跳变
   - 收起：键盘收起后面板恢复原高度；点搜索框外区域仅收键盘不关面板

3. 实现提示：
   - Android：用 WindowInsetsCompat 监听 IME 高度，
     禁止硬编码键盘高度（全面屏/带工具栏键盘高度不一）
   - iOS：keyboardWillShow 通知 + 约束动画

【验收标准】
1. 点「+」键盘收起后面板滑出，Skill 列表完整可见
2. 点击搜索框，键盘弹出后搜索框仍完整可见（距键盘上沿 ≥16dp）
3. 键盘弹出/收起全程面板平滑跟随，无跳变、无遮挡闪烁
4. 内容区可滚动，键盘弹出时自动定位到搜索框
5. 点遮罩/下拉/点关闭均可退出面板
6. 无 Skill 时显示空状态文案，不出现空白面板
